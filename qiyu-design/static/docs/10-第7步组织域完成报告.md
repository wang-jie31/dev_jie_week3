## 二、后端实现（api/）

### 1. 认证域（S-25）
- **`api/app/core/security.py`**：追加 `encrypt_id_card`/`decrypt_id_card`/`mask_id_card`
  - AES-256-GCM：随机 12 字节 nonce，密文 + nonce 均 Base64 落库（ADR-009）
  - 脱敏 `330***********5678`：保留前 3 后 4
- **`api/app/core/deps.py`**（重写）：`get_current_user` 校验 access token 并查 staff 表确认存在且 active（已删/禁用 401）；`require_role(*roles)` 返回依赖工厂，越权抛 `BizError(4010, "权限不足")`
- **`api/app/models/org.py`**：新增 `LoginLog`、`RefreshToken`（token_hash unique、revoked）、`SensitiveAccessLog`；移除重复的 SiteConfig/SiteHistoryItem（content.py 已定义）
- **`api/app/routers/auth.py`**（新）：
  - `POST /api/v1/admin/login` — 校验密码 → 双令牌 → 登录日志 → last_login_at
  - `POST /api/v1/admin/refresh` — 校验未吊销 + SHA-256 hash + 轮换新 refresh
  - `POST /api/v1/admin/logout` — 吊销 refresh（立即失效）
  - `GET /api/v1/admin/me` — 当前用户信息（侧边栏角色显示用）
- 错误码对齐《02 技术文档》§8.1：2001 密码错误 / 2002 令牌失效 / 2003 账号禁用
