## 二、后端实现（api/）

### 1. 新增 ORM：`api/app/models/lead.py`
- **Message**（messages 表）：kind(appointment/message)、status 四态、soft-delete deleted_at、threads 关系
- **MessageThread**（message_threads 表）：type 5 类（phone/wechat/sms/email/note）、author、ON DELETE CASCADE

### 2. 新增 Schemas：`api/app/schemas/lead.py`
- `ApiResponse[T]` / `ApiListResponse[T]` 泛型包裹
- `PHONE_RE = r"^1[3-9]\d{9}$"` 手机号校验
- `MessagePublicCreate`（phone 校验 + strip）、`MessageOut`/`MessageDetailOut`（含 threads）、`MessageThreadCreate`/`MessageThreadOut`

### 3. 新增服务层：`api/app/services/lead.py`
- **`sanitize_text()`** XSS 清洗（§12.4）：剥离 `<script>`/`<iframe>`/`<object>`/`<embed>` 标签 + `on*` 事件属性 + `javascript:` 协议
- **`RateLimiter`**（内存滑窗 10/min/IP，v1 不引 Redis）→ 超限抛 BizError(3004) + retry_after
- **`create_message_public()`**：校验 → 限流 → 清洗 → 落库 status='new'
- **`list_messages()`**：kind/status/source_page/keyword 筛选 + 分页（含 thread_count）
- **`get_message()`** / **`update_message_status()`**（状态机迁移表校验，违规 4003）/ **`append_thread()`**（白名单 + 清洗 + only-append）/ **`update_message_note()`**

### 4. 状态机（§4.3）— 违规流转返回 4003
```
new ──→ contacted ──→ converted（终态）
  │            │
  └──→ closed  └──→ closed
  （contacted 可回退 new）
```
非法迁移（如 new→converted）→ `code=4003 非法状态流转`

### 5. 路由追加

**公开（`routers/public.py`）**：
- `POST /api/v1/messages` — 公开提交（S-16）：name/phone 必填 + phone 正则 + kind 默认 appointment；限流 3004 返回 retry_after

**后台（`routers/admin.py` 底部，S-15）**：
- `GET /admin/messages` — 列表（kind/status/source_page/keyword/page + thread_count）
- `GET /admin/messages/{pk}` — 详情（含 threads）
- `PATCH /admin/messages/{pk}/status` — 状态流转（违规 4003）
- `POST /admin/messages/{pk}/threads` — 追加沟通记录（author=当前用户）
- 权限：LEAD_ROLES = (admin, sales, cs)（第 7 步替换完整 RBAC）
