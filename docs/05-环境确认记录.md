## 3. 环境缺口与补齐方案

### 3.1 pnpm（Node 官方包管理器，无需额外下载）

- **现状**：未启用（不在 PATH），但 Node 22 自带 **corepack 0.34.6**。
- **补齐方式**（一条命令启用，命令由我执行）：
  ```
  corepack 启用后执行：corepack enable && corepack prepare pnpm@latest --activate
  ```
  （Windows 下由 node 直接运行 corepack 的 JS 入口即可；后续命令里都用托管 node 的绝对路径，不依赖 PATH。）

### 3.2 Python venv（隔离依赖，避免污染系统）

- 用托管版 `...\python\versions\3.13.12\python.exe -m venv ...\python\envs\default` 建项目专用 venv。
- 本方案全部 Python 依赖（fastapi/uvicorn/sqlalchemy/alembic/psycopg/argon2-cffi/cryptography/pytest 等）**只装进该 venv**，第 3 步（M1）开始时安装，第 1 步暂不安装。

### 3.3 PostgreSQL 16（本机安装，替代 Docker）

- **原因**：本机无 Docker（Q2 默认方案不满足），无现成 PG。需下载安装。
- **确认状态**：用户 2026-08-26 15:20 确认「本机安装 PostgreSQL 16；D 盘能装就装 D 盘，不能就 C 盘；授权 AI 直接安装」。

- **安装要点**：
  1. 安装目录 **`D:\PostgreSQL\16`**（D 盘空间 459G 可用，优先 D 盘）；
  2. 数据目录 `D:\PostgreSQL\16\data`；
