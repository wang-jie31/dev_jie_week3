## 三、后端配套修复（前置缺口闭合）

第 4 步前台需要站点配置数据，但第 3 步 `/api/v1/site` 为占位返回。本步闭合：

| 改动 | 文件 | 说明 |
|---|---|---|
| `SiteConfig` + `SiteHistoryItem` ORM | `api/app/models/content.py` | site_config 单例（id=1，JSONB contact/social）+ history_items 时间轴 |
| `SiteService.get_public()` | `api/app/services/content.py` | 读单例 + history 排序返回；单例缺失给空默认不抛错 |
| `/api/v1/site` 接真实数据 | `api/app/routers/public.py` | 由占位改为读 site_config 单例 + 时间轴 |

## 四、ISR/SSG 路由表（构建产物）

```
┌ ○ /                   164 B   ISR 1m      (首页静态)
├ ○ /about              164 B   ISR 1m
├ ƒ /careers           1.5 kB   动态        (server-rendered)
├ ƒ /cases            2.91 kB   动态        (列表 revalidate 30s)
├ ● /cases/[slug]      638 B   ISR 1m       (3 条 SSG: sunny-one-bed / loft-no9 / wabi-2br)
├ ƒ /news             2.57 kB   动态
├ ● /news/[slug]       164 B   ISR 1m       (2 条 SSG)
├ ƒ /packages         2.59 kB   动态
└ ● /packages/[slug]   164 B   ISR 1m       (3 条 SSG)
```

> 说明：`ƒ` 动态路由在本地 `next start` 下按需服务端渲染（依赖 8000 API）；SSG 路径已在构建时预渲染为静态 HTML。`dynamicParams=true` 保证新建内容（ISR 刷新后）自动可访问。
