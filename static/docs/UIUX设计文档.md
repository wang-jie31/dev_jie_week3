## 2. 设计目标与设计原则

### 2.1 设计目标
1. **信任感**：用「真实案例 + 透明价格 + 团队档案」建立专业可信的品牌形象（对应 PRD §3.1 目标 2）。
2. **低决策成本**：套餐双轨价格、四阶段流程、精选案例大卡片降低用户认知负担（PRD §5.2）。
3. **获客闭环**：联系页预约表单路径清晰，file:// 与 http 双模式可用（PRD §7.6）。
4. **可运营**：后台五大分组 + 数据看板支撑内容运营与经营决策（PRD §8）。

### 2.2 设计原则
| 原则 | 说明 | 落地 |
|---|---|---|
| 温馨克制 | 嫩黄渐变 + 奶油底 + 墨色文字，暖而不腻 | 全站底色 `#FFFDF6/#F9F3E6` 系 |
| 内容优先 | 案例/价格/流程是主角，装饰让位 | 大面积留白 + 细边框卡片 |
| 一致 | 前台/后台共用同一黄墨色系与字体骨架 | Token 见 §4 |
| 可访问 | 对比度、焦点环、键盘可用贯穿前后台 | 见 §11 |
| 动效克制 | 微交互 150–300ms，滚动渐入 ≤0.7s，尊重 `prefers-reduced-motion` | 见 §10 |

### 2.3 参考站取舍（对应 PRD §1.5）
- **借鉴** lanniao.cn：中文主标题 + 英文副标（eyebrow）双语版式、页面 Hero 暗色大图范式、"编号化"结构化展示、首页"Hero→优势卡→网格→页脚"骨架。
- **替换**：配色由 lanniao 的红黑灰 `#e9212e/#27282c` 改为**嫩黄系**（独居温馨小家调性）；案例/套餐独立建模，不做其"文章模型混载"。

## 5. 图标与图片规范

### 5.1 图标（重点整改项）
> 技能规则：**不使用 emoji 作为 UI 图标**，应统一 SVG 图标集（Heroicons / Lucide，24×24 viewBox + `w-* h-*` 统一尺寸）。

现状问题：原型大量使用 emoji 当图标/标识（前台：导航 Logo `🏠`、优势卡、联系图标、招聘图标块；后台：Logo `🏠`、`🌐 查看前台`、`📊`、`✅`、`📈` 等）。emoji 在不同平台渲染不一、色彩不可控、不具可访问性（读屏器读法混乱）。

**逐项替换建议表：**

| 位置 | 当前 emoji | 建议 SVG（Heroicons 风格） |
|---|---|---|
| 前台 Logo | 🏠 | `home` 实心（墨色/黄底圆形） |
| 优势卡图标 | 🎨🚀⚙️💬 等 | `paint-brush` `sparkles` `cog-6-tooth` `chat-bubble-left-right` |
| 联系信息卡 | 📞✉️📍 | `phone` `envelope` `map-pin` |
| 招聘图标块 | 💼 | `briefcase` |
| 后台 Logo | 🏠 | `home` / 品牌首字 |
| 查看前台 | 🌐 | `globe-alt` |
| 概览看板标题 | 📊📈 | `chart-bar` `trending-up` |
| 状态/标记 | ✅ | `check-circle`（或统一用徽章色块） |
| 弹窗关闭 | ×（文本） | `x-mark`（或保留文本 ×，非 emoji，可接受） |
| 精选案例箭头 | →（文本） | `arrow-right`（当前为 `::after` 文本箭头，可保留或换 SVG） |

### 5.2 图片规范
- 封面/图集统一 `object-fit: cover`；卡片图片高度固定（案例卡 210px、精选卡 4:3、信息卡 160px），避免跳动。
- 占位图：原型用 `placehold.co/74`（后台缩略图）与 Unsplash（前台场景图），生产化替换为真实图库 + CDN。
- 懒加载：`loading="lazy"`；关键首屏图（Hero）不懒加载。
- `alt`：所有有意义的图片必须带描述性 alt（Logo/装饰图可 `alt=""`）。
- 图片 hover：`transform: scale(1.04–1.05)` 微缩放（`transition .5–.6s`），不引起布局位移。

## 6. 前台组件规范（`index-v7.html`）

### 6.1 导航（Desktop）
- 结构：Logo（`🏠 栖屿设计`，占位）+ 一级项 **首页 / 案例展示 / 服务套餐 / 新闻资讯 / 招聘入口 / 关于我们**（对应 PRD §6.1 的 5 个一级项 + 首页）+ 右侧 CTA **预约咨询**（`btn-yolk` 胶囊）。
- 交互：hover 显示下拉（`.nav-dropdown`：`opacity 0→1 + translateY(8px→0)`，0.2s）；当前项 `aria-current="true"` 显示金黄下划线（`::after` 宽 0→100%，0.22s）并着色 `#C8951F`。
- 键盘：`focus-visible` 显示 `2px solid #EDB93F` 焦点环；下拉支持 `:focus-within` 展开。
- 移动端（≤768px）：汉堡菜单展开抽屉式导航，含全部一级项与二级项 + 预约咨询 CTA。

### 6.2 页面 Hero（内页）
- 结构：暗色大图（Unsplash 室内图）+ 底部渐变遮罩 `rgba(39,40,44,.55→.75)` + 居中内容（eyebrow 英文 + 中文大标题 + 副标题）。高度 320–420px。
- 用于：案例/套餐/新闻/招聘/关于 各内页顶部（对应 PRD §7 各页）。

### 6.3 按钮
| 类型 | 样式 | 状态 |
|---|---|---|
| 主按钮 `btn-yolk` | 半透明渐变黄 `rgba(247,208,106,.42→rgba(252,233,166,.46)` + 边框 `rgba(237,185,63,.35)` + 墨色文字 + 胶囊圆角 + `backdrop-filter: blur(4px)` | hover：渐变加深 + `translateY(-1px)` + 阴影；active：归位 |
| 深色按钮（后台新增） | `bg-[#4A3F30] text-white` | hover `#3a3226` |
| 文字按钮/链接 | 蓝 `#2F6DB5`（编辑）/ 红 `#C0392B`（删除） | hover `underline` |

### 6.4 卡片
- 通用 `.card`：奶油底 + `1px solid #F0E3BE` + 圆角 1rem + hover 浮起（阴影 + `translateY(-3px)`，0.25s）。
- 案例图片卡：上图（210px，hover 内图 scale 1.05）下文（标签/标题/元信息），整卡可点（`cursor-pointer`）。
- 横向信息卡（新闻/招聘）：`200px 封面 + 1fr 内容`（标签 + 衬线标题 + 摘要 + 右侧元信息），≤640px 单列。
- 招聘卡：`120px 图标块 + 1fr 信息`，图标块渐变黄底 + 44px SVG。
- 联系信息卡：三列居中（56px 圆图标 + 标题 + 描述），hover 上浮 4px。
- 团队卡：88px 圆头像（渐变黄底 + 姓氏衬线首字）+ 姓名/职位/专长。
- 流程卡：Inter 大号编号 `2.25rem #F7D06A` + 标题 + 描述（编号化结构化展示，呼应 PRD §5.3）。

### 6.5 精选案例大卡片（首页核心视觉，PRD §7.1）
- 布局：`grid-template-columns: 1.15fr 1fr`，奇偶翻转（`.reverse` 换列 + 图右移），间距 3rem；≤768px 单列堆叠。
- 图块：4:3 圆角 14 + 阴影；右上/左上浮动分类 chip（奶油底 95% + 毛玻璃 + `#8B6C23`）；hover 内图 scale 1.04。
- 信息块：红品牌标签 `QIYU · 栖屿精选`（Inter 12px 字距 0.22em 大写 `#C73E3A`）+ Noto Serif 大标题（1.9rem）+ **红描边描述框**（`1px solid #C73E3A` 圆角 6，浅红底，两段简介，行高 1.85）+ 属性行（面积·风格·价格·地址，13px muted）+ 「查看详情 →」链接（hover 箭头右移）。
- 数据：取「精选案例」前 3 条，简介取 `summary` + `content` 首段。

### 6.6 表单（联系我们 / 预约，PRD §7.6）
- 字段：姓名、手机号、预算区间、需求描述；提交后提示成功、必填校验 inline 报错。
- 双模式：http 同源 POST；file:// 直开走 JSONP（`GET /api/v1/messages?callback=`）回退，顶部提示横幅引导用 http 访问。
- 视觉：奶油底卡片 + 圆角输入框 + `btn-yolk` 提交按钮；焦点 `border-color` 变金黄。

### 6.7 筛选 chips / 分页 / 轮播 / 地图
- 筛选 chips（`.fchip/.nchip`）：多组维度（分类/风格/户型/面积），active 渐变黄底 + 金黄边框（0.18s 过渡）。
- 分页：上一页 / 1 2 3… / 下一页，当前页高亮 `btn-yolk`；筛选变化自动回第 1 页。
- Hero 轮播：`transition .6s cubic-bezier(.4,0,.2,1)`；圆点指示器 9px，active 变 26px 长条黄；左右箭头。
- 高德地图：`.map-wrap` 圆角 16 边框 1px，min-height 420px，iframe 撑满；与预约表单等高对齐。

### 6.8 页脚
- 品牌一句话 + 快速链接 + 社媒矩阵（微信/视频号/抖音/小红书占位）+ 版权与备案号；页面路由切换时页脚常驻。

## 7. 后台组件规范（`admin.html`）

### 7.1 登录页
- 居中卡片：Logo（🏠 占位）+ 品牌名 + 账号/密码输入（焦点金黄环）+ 登录按钮（`btn-yolk`）+ 错误提示区 + 底部「🌐 查看前台网站」入口。
- 交互：未登录自动聚焦账号框；登录成功写 JWT 与角色到 localStorage。

### 7.2 侧边栏（232px 固定，PRD §8）
- 结构：品牌区 + 5 分组导航（**概览 / 内容管理 / 客户管理 / 业务管理 / 人力与资源**）+ 底部退出按钮。
- 分组可折叠：标题带 `▾` 箭头（`.nav-caret`），点击收回/展开其下子项（`.nav-collapsed` `display:none!important`），箭头旋转 90°，状态存 `localStorage('qiyu_nav_collapsed')`，刷新保持。
- 角色显隐：按 `PAGE_ROLES` 整组/整项隐藏（`applyRoleNav`）；无权限分组连标题一起隐藏。
- 当前项：渐变黄底 + 600 字重 + 黄点（`.nav-item.active`）。

### 7.3 顶栏

## 11. 响应式与无障碍

### 11.1 断点与响应式（技能规则 + PRD §10）
| 断点 | 行为 |
|---|---|
| ≥1024px | 前台多列网格、桌面导航；后台侧边栏常驻 |
| 768–1023px | 卡片列数收缩；精选案例/信息卡保留双列或转单列 |
| ≤768px | 汉堡导航；精选案例大卡片单列堆叠；联系信息卡单列 |
| ≤640px | 信息卡/招聘卡转单列；表格类页面保持横向可滚动容器（后台建议 `overflow-x-auto`） |

### 11.2 无障碍（技能 CRITICAL 优先级）
- **对比度**：正文 `#4A3F30` / `#9A8C75` 于奶油底均 ≥4.5:1；弱化文字不低于 `#475569` 级别（后台 `#9A8C75` 于白底约 4.6:1，可接受；不建议再浅）。
- **焦点**：`a:focus-visible, button:focus-visible` 统一 `2px solid #EDB93F + offset 3px`（前后台已实现）。
- **表单**：label 与 input 关联（`for/id`）；错误信息紧邻字段并 `aria-describedby`。
- **键盘**：Tab 顺序与视觉一致；下拉可 `:focus-within` 展开；弹窗 Esc 可关（建议补）、保存后焦点归还触发元素（建议补）。
- **颜色非唯一指示**：状态徽章同时有文字（如「已上架」），不单靠颜色；图表配图例。
- **图片**：alt 全覆盖；装饰图 `alt=""`。
- **触摸目标**：按钮/链接最小 44×44px（当前 `px-3.5 py-2.5` 导航项接近，移动端建议加 padding 补足）。
