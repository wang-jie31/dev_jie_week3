## 二、后端成果（api/）

### 2.1 认证契约实现（§8.1）

```
POST /api/v1/admin/login    username/password → access_token(2h) + refresh_token(8h) + user
POST /api/v1/admin/refresh  refresh_token → 新 access_token + 轮换 refresh_token
POST /api/v1/admin/logout   refresh_token → 吊销（refresh_tokens.revoked=true）
GET  /api/v1/admin/me       当前登录人信息
```

错误码契约：**2001** 用户名/密码错误 · **2002** 令牌失效/已吊销 · **2003** 账号禁用

### 2.2 安全关键实现

| 模块 | 内容 |
|---|---|
| `core/security.py` | argon2id 密码哈希；AES-256-GCM 身份证加密（`encrypt_id_card` → enc_b64 + nonce_b64，12B 随机 nonce）；`mask_id_card` → `110***********1234`（保留前3后4）；**JWT `jti` 字段**（uuid4.hex，防同秒并发刷新 UniqueViolation） |
| `core/deps.py` | `get_current_user`（校验 token + 查 staff 存在且 active，已删/禁用 → 401）；`require_role(*roles)` → 越权 `BizError(4010, "权限不足")`（HTTP 体 code=4031 兼容契约） |
| `models/org.py` | `Department`/`Staff`（id_card_enc/id_card_nonce、role CHECK、salt/password_hash）+ 新增 `LoginLog`/`RefreshToken`（token_hash 唯一、可吊销）/`SensitiveAccessLog`（审计） |
| `services/org.py` | `AuthService`（登录写日志+last_login_at）/`StaffService`（CRUD + reveal_id_card 明文审计）/`DepartmentService`（删部门置空员工）/`LoginLogService`（分页 + CSV 防注入导出）/`SiteConfigService`（含 history_items 全量替换） |

### 关键修复记录

- `Table 'site_config' is already defined`：org.py 移除重复 SiteConfig/SiteHistoryItem（content.py 已有）
- login-logs 500：输出 Schema 补 `model_config = ConfigDict(from_attributes=True)`
