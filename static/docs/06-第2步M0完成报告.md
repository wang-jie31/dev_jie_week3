## 二、S-01 workspace 脚手架

### 目录结构

```
qiyu-design/
├── package.json          # npm workspaces 根配置
├── package-lock.json
├── .npmrc                # npmmirror registry（npm 标准）
├── apps/
│   ├── web/              # Next.js 15 前台（SSG/ISR）
│   └── admin/            # Vite + React SPA 后台
├── packages/
│   ├── ui/               # 共享 design tokens（@qiyu/ui/tokens.css）
│   └── api-types/        # OpenAPI 生成类型（@qiyu/api-types）
├── api/                  # FastAPI 模块化单体后端
│   ├── app/              # core / routers / models / schemas...
│   ├── alembic/          # 迁移（versions/0001_initial.py）
│   └── requirements.txt
├── scripts/              # generate-api-types.mjs 契约脚本
└── deploy/               # 部署准备（后续步骤填充）
```

### 关键决策：pnpm → npm workspaces

| 项 | pnpm | npm workspaces（选定） |
|----|------|------------------------|
| 符号链接 | 依赖符号链接，Windows+沙箱下 app 级 node_modules 链接失效 | 平铺 node_modules，无符号链接依赖 |
| store 清理 | 清理触发安全删除拦截（3 万+ 文件）无法自愈 | 无 store 概念，install 直接完成 |
| 依赖协议 | `workspace:*` | `*`（根配置自动链接本地包） |
| 结论 | ❌ 不稳定 | ✅ 49s / 185 包成功 |

## 七、本次踩坑记录（供后续参考）

| 问题 | 修复 |
|------|------|
| alembic.ini 中文注释 → GBK 解码失败 | 重写为纯 ASCII（英文注释），SQLAlchemy URL 运行时从 .env 注入 |
| CheckConstraint 跟在关键字参数后 → SyntaxError | 移到 `sa.Column` 位置参数区 |
| pnpm 符号链接失效 + store 清理拦截 | **切换到 npm workspaces**（见 S-01 决策表） |
| npm 不识别 `workspace:*` | 子包依赖协议批量替换为 `*` |
| 脚本找不到 fastapi | findPython() 优先托管 venv 路径 |
| openapi-typescript bin 链接 ENOENT | 直接 `node <cli.js 路径>` 执行 |
| Vite 清空 dist 触发安全删除 | 构建前 rename `dist` → `dist_old_<时间戳>` |
| react-router v7 无 NavLink/Outlet 导出 | react-router-dom v7 薄壳，依赖 react-router 同版本链接（npm 平铺布局解决） |
