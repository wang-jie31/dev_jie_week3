## 二、后端成果

### 2.1 数据模型（`api/app/models/delivery.py`）

- `Project`（projects 表）：9 态 CHECK 约束 + `progress` 0-100 + `code` 唯一索引 + `site_id` 循环外键
- `ConstructionSite`（construction_sites 表）：工地主数据
- 循环外键修复：`site_id` 带 `ForeignKey(..., ondelete="SET NULL")`；`Project.site` relationship 设为 `viewonly=True`（两向 MANYTOONE 会报 SQLAlchemy `ArgumentError`）

### 2.2 状态机（§4.3，9 态）

```
lead → measuring → designing → quoting → signed → constructing → acceptance → done
任意非终态 → cancelled；done / cancelled 为终态
违规迁移 → code=4003 非法状态流转
```

- `PROJECT_TRANSITIONS` 集中定义合法迁移表（后端 service 与前端页面共用同一语义）
- `done`/`cancelled` 自动置 `progress=100`；进度 PATCH 越界（＜0 或 ＞100）→ `code=3001`

### 2.3 编号自动生成

`QY-{yyyy}-{seq}`：同年序列 +1、四位补零（实测 `QY-2026-0001/0002`）

### 2.4 overview 聚合（S-21，§6.4.2）

| 区块 | 内容 |
|---|---|
| kpi | 9 项：cases_total/cases_delta · packages_total · messages_total/messages_delta · projects_total/projects_active · team_count · sites_count |
| north_star | 北极星：本月有效线索（new/contacted/converted） |
| 状态分布 | message_status_dist / project_status_dist 分组计数 |
| trend_6m | 近 6 月双序列（projects 新增 / appointments 预约），`date_trunc('month')` |
| designer_rank | 设计师项目排行 TOP10（未分配合并） |

### 2.5 新增路由（`api/app/routers/admin.py`）

```
GET/POST   /api/v1/admin/projects            列表/新建
GET/PUT/DELETE /api/v1/admin/projects/{pk}   详情/编辑/软删
PATCH      /api/v1/admin/projects/{pk}/status  9 态流转（4003）
PATCH      /api/v1/admin/projects/{pk}/progress 进度（3001）
GET/POST   /api/v1/admin/sites               列表/新建
GET/PUT/DELETE /api/v1/admin/sites/{pk}      详情/编辑/硬删
GET        /api/v1/admin/overview            聚合看板
```
