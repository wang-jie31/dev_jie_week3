## 四、本次解决的问题

| 问题 | 解决 |
|------|------|
| `.env` 读取路径算错（config.py parents[3] → 指向 qiyu-design 而非项目根） | 改为 parents[4] 优先（项目根 .env），无则回退 parents[3] |
| `ContentViewStat` 复合主键无 primary_key → ORM 报错 | 三列都标 primary_key=True（注意 CheckConstraint 位置参数坑） |
| staff/team_members/uploads 外键引用 staff 表但 org 模型缺失 | 建最小 org 域 stub（staff/department） |
| 测试中 staff id 是 GENERATED ALWAYS 不能显式插入 | 改为自动自增 + 动态 JWT（真实 id） |
| 8000 端口被第 2 步旧 FastAPI 残留占用 | taskkill `/F /PID` 释放后重启 |
